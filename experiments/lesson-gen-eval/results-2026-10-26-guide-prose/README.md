# guide 變成 TTS 講解：觀察、修正、驗證（2026-10-26）

## 問題
deepseek 把 `@guide` 寫成敘述，重講 `@tts` 的話；而且沒有函式呼叫的程式也加 `[標籤#顏色]`（沒有呼叫圖，標籤無用）。
人工教案裡，沒有函式呼叫的程式（factor_sum、collatz、palindrome）完全沒有 guide。

## 修正前的基準（上一輪最終端到端，18 份，`../results-2026-10-26/route-eval-final/`）
guide 行 169；純敘述（無 `{…}`）43（25%）；與 tts 字元 bigram 重疊 ≥ 50% 且 ≥ 6 字 31。

## 修正（commit `f0bed6b8`）
1. 系統提示規則 12：guide 只放變數／容器；敘述寫 @tts；只有 main 時不寫 `[標籤#顏色]` 與純文字 guide；有函式呼叫時呼叫圖標籤是 guide 唯一可寫文字之處。
2. `drop_prose_guides`：只有 main 的程式，確定性移除沒有 `{變數}` 的 `@guide`。
3. `score_lesson.py` 新增 S7（只有 main 時純敘述 guide 的數量）。

## 驗證（`route-eval/`，6 題 × 3 次，3 並行，打真正的 `/api/generate_lesson`，拋棄式容器）
| | 修正前 | 修正後 |

| 通過 G 門檻 | 18/18 | 18/18 |
| 純敘述 guide（合計） | 43 | 16 |
| 與 tts 高重疊（合計） | 31 | 9 |

分題（舊 → 新，guide 行 / 純敘述 / 高重疊）：
for 24/5/3 → 21/0/2；while 28/7/2 → 25/0/0；dp 24/9/11 → 16/0/3；
vector 12/4/1 → 6/0/0；string 42/13/7 → 40/13/2；recursion 39/5/7 → 38/3/2。

三個只有 main 的題（for、while、dp）純敘述 guide 全部降為 0，且只有 1 份靠確定性移除，其餘是提示詞規則 12 本身生效。
string、recursion 有其他函式，剩下的「純敘述」多半是只有標籤的 `[初始化#blue]`，是呼叫圖節點文字，屬於允許的用法（§2.8），並非問題。

## 限制
- 只有 6 題 × 3 次；耗時下降（261 → 185 s）可能與限流或當下負載有關，不應解讀為本修正的效果。
- 「重疊」用字元 bigram 近似，不是語意判斷；「純敘述」以有無 `{` 判斷。
- 教學品質（Q 項）仍未量測。
- 人工教案在只有 main 時也會寫 1–2 行純敘述 guide（67 份中 42 份 S7=1），本規則比人工慣例更嚴格，屬於政策選擇。
