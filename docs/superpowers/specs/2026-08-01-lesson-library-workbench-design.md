# 教案庫題庫工作台設計

## 目標

將教案庫改為適合大量瀏覽的「題庫工作台」。視覺與操作節奏參考 LeetCode 題庫的高密度清單、搜尋與篩選方式，但不使用其品牌、圖示或資產。

## 已確認決策

- 採用「題庫工作台」版型，而非側欄導覽或卡片牆。
- 不新增難度、適用年級、收藏、熱門度、排序或其他資料欄位。
- 沿用現有教案資料與路由；本次不調整後端模型或 API。
- 保留所有既有行為：搜尋、標籤篩選、分頁、開啟教案、擁有者刪除，以及自己的教案提示。
- 登入後的共用頁面新增上方導覽列，讓使用者隨時返回教案庫或開啟自己的個人檔案。

## 版面與視覺

### 桌面版

1. 在頁面最上方加入共用導覽列：左側為網站／教案庫入口，右側顯示目前使用者名稱並連到既有個人檔案頁，旁邊保留登出入口。
2. 將目前置中的窄卡片改成全頁寬的內容工作區，保留明確的外側留白。
3. 頂端為「教案庫」標題與教案總數。
4. 標題下方放置寬搜尋列；標籤篩選以可換行的小型按鈕排列，選中狀態清楚可辨。
5. 清單改為帶欄位標頭的資料表式列表：
   - 編號／自己的教案標記
   - 教案標題與標籤
   - 作者
   - 更新時間
6. 每一列保留整列可開啟的明確互動，擁有者的刪除按鈕維持獨立且不可誤觸。

### 色彩與字體

- 延續目前的白底、墨藍灰文字與靛藍互動色，讓改版與全站風格一致。
- 使用深藍灰作為工作台的結構色，白色清單表面與細緻分隔線提高掃讀性。
- 編號維持等寬字與低對比色；自己的教案使用既有暖色標記，不新增另一套狀態系統。

### 手機版

- 搜尋與標籤維持完整可用。
- 欄位標頭隱藏；單列改為直式資訊排列，標題優先，作者與更新時間置於次要資訊列。
- 不引入水平捲動；刪除按鈕仍具有足夠點擊範圍。

## 可及性與相容性

- 保留實際搜尋表單與連結，不以 JavaScript 模擬導覽。
- 上方導覽列的個人檔案入口使用既有個人檔案路由，且有清楚的鍵盤焦點狀態。
- 標籤、分頁、列連結與刪除按鈕須保有可見焦點狀態。
- 保留既有 `data-testid`，避免破壞端對端測試。
- 空清單、搜尋無結果與分頁邊界的現有文案與行為維持不變。

## 不在本次範圍

- 新增資料欄位、資料庫遷移或 API。
- 新增或重做個人檔案頁功能；本次只提供既有頁面的入口。
- 收藏、難度、推薦、熱門度、拖曳、無限捲動或前端框架重寫。
- 複製 LeetCode 的商標、品牌配色、圖示或具識別性的元件。

## 驗收條件

1. 桌面版能在單一清單中快速辨識標題、標籤、作者與更新時間。
2. 現有搜尋、標籤篩選、分頁、開啟與擁有者刪除均可正常使用。
3. 手機寬度下資訊不重疊、不產生水平捲動，操作目標可點擊。
4. 既有教案分享相關測試與端對端選擇器持續通過。
