v.at(i) 會先檢查索引，超出就報錯；v[i] 不檢查。IRIS 替 v[i] 加了檢查，所以停在這一行。

3怎麼改

v 有 5 格，條件要寫 i < 5（或 i < v.size()）。

for (int i = 0; i < 5; i++) {
和原生 Linux 比較：g++ 編譯的程式不會報錯，跑完並印出 5；寫進 v[5] 的值落在 vector 的範圍外。
原始錯誤訊息（第 6 行）
vector[] index out of bounds

這個訊息來自 C++ 標準函式庫（libc++）的檢查，只有行號。

實作時要注意（從這次的實測資料看到的）

  • C 陣列越界：索引和陣列大小來自錯誤紀錄（index 4、int[4]）；格子裡的值來自軌跡那一步的 b.data。
  • vector 越界：錯誤紀錄只有行號和 libc++ 的訊息，values 是空的。i = 5、v 的內容和 capacity 都要從軌跡那一步取；一行裡有好幾個 [] 時，要等 P4 的「容器下標精確定位」才能確定是哪一個。
  • capacity 比 size 大時，size 線右邊加畫虛線格（已配置、還沒用的空間）；這個例子兩個都是 5，所以沒有虛線格。
  • 記憶體排列圖在按「繼續」、那次寫入真的發生之後才出現。越界寫到各自宣告的區域變數時，排列會因環境不同，圖上要註明（11-05 決定）；struct 成員的排列由 C++ 規則決定，不必註明。
