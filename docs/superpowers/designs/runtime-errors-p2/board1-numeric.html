實作時要注意（從這次的實測資料看到的）

  • 除以零的 a、b 值直接來自錯誤紀錄（lhs 7、rhs 0）；溢位的兩個運算元也是（479001600、13）。位元格與數線由這兩個數算出來，不必再查軌跡。
  • 「值從哪裡來」要在軌跡裡往回找變數最後一次改變的那一步；b 是 cin 讀進來的，所以改成指向輸入那一行和程式輸入欄。
  • 正確答案若剛好讓第 32 位變成 1（例如 2147483647 + 1），下排第一格要標紅，說明「變成負數」；這個例子是正數，所以沒有標紅。
